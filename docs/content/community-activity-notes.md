# 커뮤니티 활동에 적을 내용

공개 문구는 확인된 참여와 역할을 기준으로 작성한다. 기수, 날짜, 발표·스터디 주제와 성과는 확인 후 추가한다.

| 커뮤니티 | 현재 반영한 내용 | 더 적으면 좋은 내용 |
| --- | --- | --- |
| SIPE | 5기, 1차 미션 디자인 시스템(@sipe-team/side) 시맨틱 토큰·접근성 훅·반응형 Flex 구현 및 공식 사이트 마이그레이션, 2차 미션 Linktrip 장소 후보 필터링 및 공유 화면 개발 | 발표나 공유한 내용, 추가 미션 기록 |
| SSAFY | 8기 Java 트랙, 알고리즘 스터디장, 출결 소명서 서비스 개발·배포·운영, 현재 멘토 활동 | 멘토링 주제와 방식, 스터디 운영 방법, 공개 가능한 발표·서비스 링크 |
| GDSC CAU | 매주 웹 개발 학습과 공유, MOA의 1인 기획·프론트엔드·백엔드·DB·배포, 사용자 피드백 반영 | 활동 기수·기간, 발표 주제, 피드백으로 실제 바꾼 기능, 프로젝트 기록 링크 |
| 피로그래밍 | 14기, 습관 형성 서비스 DOWITH 팀장(기획·DB 모델링·개발·AWS EC2 배포), 15·16기 Django 환경 구축 및 17·20기 배포 실습 세션 진행 | 추가 멘토링·운영 기록 |
| UMC | 2기 중앙대 지부 Node.js 파트, Express·MySQL 계층형 REST API 학습, 팀 프로젝트(Money Heist 성격 유형 테스트) 서버 API 개발·배포 | 데모데이·운영 지표 |
| SOPT | 26기 기획 파트, 제16회 APPJAM Booster 기획·PM, 사용자 흐름·우선순위·일정과 협업 조율, 대상 | 팀 구성, 조율했던 구체적인 결정, 공개 발표·프로젝트 링크 |

## 문구 구성

`어떤 활동에서 → 맡은 역할 → 직접 한 일 → 결과나 공개 기록` 순서로 두세 문장 정도 적는다.
