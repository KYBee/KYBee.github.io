# 경력 항목 간격 조정 설계

## 1. 배경

`# 경력` 영역의 회사별 구분선을 제거하면서, 구분선과 함께 적용되던
회사 블록 사이 여백도 사라졌다. 현재는 각 경력 설명의 아래쪽 기본 여백
12px만 남아 다음 회사 제목이 지나치게 가까워 보인다.

구분선 없는 단순한 위계는 유지하되, 각 회사를 별도 경력 블록으로 인식할
수 있을 만큼의 수직 여백을 복원한다.

## 2. 결정

- 회사별 경력 블록 사이 간격은 24px로 한다.
- 기존 간격 토큰 `var(--space-5)`를 사용한다.
- 데스크톱과 모바일에 같은 값을 적용한다.
- 첫 번째 경력 블록 위와 마지막 경력 블록 아래에는 새 여백을 추가하지
  않는다.
- 경력 구분선은 다시 추가하지 않는다.

24px는 비교한 24px, 32px, 48px 안 중 사용자가 선택한 값이다. 경력 목록의
밀도를 유지하면서 현재 12px보다 회사 전환을 분명하게 만드는 것을
우선한다.

## 3. 구현 범위

`src/components/Workspace.astro`의 기존 `.job-group` 구조는 그대로 유지한다.
인접한 경력 블록에만 적용되는 다음 관계를 스타일로 표현한다.

```css
.job-group + .job-group {
  margin-top: var(--space-5);
}
```

인접 형제 선택자를 사용하므로 첫 블록과 경력 영역 바깥의 여백에는 영향을
주지 않는다. 별도의 반응형 덮어쓰기는 만들지 않는다.

다음 항목은 변경하지 않는다.

- 회사명, 역할, 기간, 지역과 설명의 마크업 및 콘텐츠
- 한 회사 블록 내부의 12px 간격
- 아바타와 메시지 레이아웃
- 다른 채널과 프로젝트 블록의 간격
- 한국어와 영어의 렌더링 구조

## 4. 검증

자동 검증은 다음 계약을 보호한다.

- 빌드된 한국어와 영어 페이지에 기존 경력 위계 클래스가 존재한다.
- `job-hr` 구분선은 존재하지 않는다.
- 인접한 `.job-group` 사이에 `var(--space-5)` 간격이 적용된다.

브라우저에서는 데스크톱과 모바일 너비에서 다음을 확인한다.

- 세 회사 블록이 구분선 없이도 서로 구별된다.
- 첫 블록 위와 마지막 블록 아래의 기존 여백이 변하지 않는다.
- 24px 간격이 두 화면 크기에서 동일하다.
- 다른 채널의 레이아웃과 간격에는 변화가 없다.

## 5. 완료 조건

- 회사별 경력 블록 사이에만 24px 수직 여백이 표시된다.
- 구분선은 표시되지 않는다.
- 한국어와 영어, 데스크톱과 모바일에서 같은 동작을 한다.
- 관련 자동 검사와 전체 사이트 검증이 통과한다.
